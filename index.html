      What is a UTM builder?

      A UTM builder adds tracking tags to a link so GA4 (or any analytics tool) knows where a visit came from. Google has its own Campaign URL Builder, and it's fine, but it won't tell you that utm_medium=newsletter ends up as Unassigned in GA4. This one checks your values against the GA4 default channel group rules as you type, keeps your naming consistent, does bulk links, and makes a QR code for each link.

      How to use this UTM link generator

      1. Paste your page URL. Existing query strings and #anchors are kept in the right place.
      2. Pick a preset or fill the fields. Presets set a source and medium that GA4 classifies properly.
      3. Check the GA4 channel badge. It shows which default channel the link lands in and which rule matched. Fix anything in the warnings list.
      4. Copy, save or download the QR code. PNG for screens, SVG for print. Use Copy builder link to send the same setup to a teammate.

      GA4 default channel group rules for UTM parameters

      GA4 checks these rules top to bottom and the first match wins. Matching ignores case. "Paid pattern" means the medium matches ^(.*cp.*|ppc|retargeting|paid.*)$, so cpc, cpm, paid-social and retargeting all count. Source lists (search, social, video, shopping sites) are maintained by Google; this tool knows the common ones.

      The shopping pattern is ^(.*(([^a-df-z]|^)shop|shopping).*)$. It means a campaign named shoe-shop or eshop-launch gets pulled into a Shopping channel, while workshop doesn't. Easy to trip over, so the builder warns you.

      UTM naming conventions that keep GA4 clean

      • Lowercase everything. GA4 treats LinkedIn and linkedin as two sources.
      • No spaces. Use hyphens (or underscores, just pick one). Spaces turn into %20 or + and get mangled when people copy links.
      • Keep a short list of mediums. email, social, paid-social, cpc, display, referral, affiliate, audio, sms. Anything else needs a custom channel group.
      • Source is the who, medium is the how. utm_source=linkedin&utm_medium=paid-social, not utm_source=paid&utm_medium=linkedin.
      • Put the date or quarter in the campaign. webinar-2026-11 sorts nicely and doesn't collide with next year.
      • Use utm_content to compare creatives. video-a vs video-b, or header-link vs footer-link.
      • Never tag internal links. It restarts the session and wipes the real source.
      • Write it down. Export the history CSV and keep it in a shared drive so the whole team uses the same names.

      UTM parameters and GA4: FAQ

      What are UTM parameters?

      UTM parameters are tags you add to the end of a link, like ?utm_source=newsletter&utm_medium=email&utm_campaign=spring-sale. When someone clicks, analytics tools such as GA4 read them and record where the visit came from.

      Which UTM parameters does GA4 need?

      Google says to always use utm_source, utm_medium and utm_campaign. utm_term, utm_content, utm_id and utm_source_platform are optional. GA4 decides the channel mostly from source and medium.

      Why is my campaign traffic showing as Unassigned in GA4?

      Usually because utm_medium is a value GA4 does not recognise, such as qr, print, partner or newsletter. Use a medium from the GA4 default channel rules (email, social, paid-social, cpc, referral, affiliate, audio and so on) or build a custom channel group.

      Are UTM parameters case sensitive?

      Yes. GA4 reports Facebook, facebook and FACEBOOK as three different sources. Pick lowercase and stick to it.

      Should I use UTM tags on Google Ads links?

      Usually not. Turn on auto-tagging in Google Ads and link it to GA4. Auto-tagging gives more detail than manual tags. Use UTMs for every other platform.

      What utm_medium should I use for a QR code on a flyer?

      There is no print or QR channel in the GA4 default channel group, so any medium like print or qr lands in Unassigned. Keep a consistent value such as print and add a custom channel group in GA4 that maps it to an Offline channel.

      Should I use UTM tags on internal links?

      No. Tagging links between pages on your own site starts a new session with the tag values and overwrites the real source. Only tag links that live somewhere else.

      Is this UTM builder private?

      Yes. Everything runs in your browser. Links, history and CSV files never leave your device, and the page has no analytics or cookies.
